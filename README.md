# 선명하게 — 사진 선명도 보정

브라우저에서 사진의 선명도를 조절하고 원본 크기 또는 2·3·4배로 저장하는 웹 앱입니다. 사진은 기기 안에서 처리하며 서버에 업로드하지 않습니다. AI 모델이나 외부 라이브러리를 사용하지 않습니다.

## 사용법

사진을 한 번에 최대 10장 선택하고 배율과 선명도를 정한 뒤 보정 버튼을 누르세요. 모든 사진이 같은 설정으로 순서대로 처리됩니다. 각 결과 아래의 다운로드 버튼으로 PNG를 저장할 수 있습니다. 결과가 너무 크면 배율을 낮춰 주세요. 결과는 사진당 최대 6400만 픽셀, 한 변 최대 16384픽셀로 제한되며 기기에 따라 더 작은 이미지에서도 메모리가 부족할 수 있습니다.

## 처리 방식

인접한 픽셀의 차이를 이용해 경계 대비를 높인 다음 브라우저의 이미지 보간 기능으로 확대합니다. 보정 강도를 높이면 노이즈나 테두리가 강조될 수 있습니다. 흐림으로 사라진 정보가 복원되는 것은 아닙니다.
